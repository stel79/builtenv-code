Quick start

Run locally

git clone https://github.com/stel79/builtenv-code.git
cd builtenv-code
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/sample_building_logic.py --name "Example Tower" --floors 12 --area 5400 --year 2026 --json

Open prototype

Open prototype.html in your browser and use the Download buttons to export a PNG or save the interactive page.
